This repository contains the tasks completed as part of the CODSOFT Python Programming Internship.

## 📋 Tasks Included

### ✅ Task 1: To-Do List (GUI - Tkinter)
A simple To-Do List application built using Python and Tkinter.
- Add tasks
- Update tasks
- Delete tasks
- User-friendly interface

File: `todo_list_gui.py`

### ✅ Task 3: Password Generator
A Python application that generates strong and random passwords.
- User specifies password length
- Uses letters, digits, and special characters
- Displays generated password

File: `password_generator.py`

### ✅ Task 4: Rock-Paper-Scissors Game
A fun command-line game where the user plays against the computer.
- Random computer selection
- Game logic implementation
- Score tracking
- Play again option

File: `rock_paper_scissors.py`
